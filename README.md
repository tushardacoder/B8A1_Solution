# B8A1_Solution


## Assignment Overview

This assignment covers  TypeScript concepts through practical coding exercises and technical blog writing.

## Completed Tasks

1. **Optional Parameters:** Implemented `multiplyValue()` using optional parameters and nullish coalescing.
2. **Union Types and Type Narrowing:** Implemented `processInput()` to handle string, number, and boolean inputs.
3. **Tuples and Readonly:** Implemented `formatCoordinate()` using a readonly tuple.
4. **Generics and Rest Parameters:** Implemented `concatenateArrays()` to combine multiple arrays.
5. **Interfaces and Filtering:** Defined a `Course` interface and implemented `getPopularCourses()`.
6. **Generic Constraints:** Implemented `pluckValues()` using `keyof`.
7. **Classes and Inheritance:** Created `Employee` and `Manager` classes using access modifiers and inheritance.
8. **Asynchronous Programming:** Implemented `validateAgeAsync()` using Promises, resolve, reject, and `setTimeout`.
